OLBG structure — what we could and could not read

Route taxonomy (from the official sitemap, read this session)

Hub URLs follow /betting-tips/<Sport_Name>/<sport_id> with underscores, not hyphens: Tennis/3, Golf/5, Cricket/7, Snooker/8, Rugby_Union/9, Rugby_League/10, Baseball/12, Ice_Hockey/13, Motor_Racing/14, Darts/15, Handball/20, Volleyball/21, Gaelic_Football/25, Greyhounds/28. Hyphenated slugs such as /betting-tips/Ice-Hockey/13 return 404 — a first-pass trap.

Markets described on the hubs

The hockey hub documents money line, puck line (−1.5 / +1.5) and totals (usually 5.5, with pushes at whole numbers). The tennis hub documents win match, set betting, total games, first-set winner and a games-won handicap. The rugby union hub documents match winner and handicap and publishes its own five-season favourite and total-points tables. Those definitions shaped the market set originated here.

The blocker

All seven hub pages read (Tennis, Ice Hockey, Rugby Union and the sitemap-indexed others tested in earlier sessions) returned “No tips found.” in the fetched document. The tips table is populated client-side, so the events and prices OLBG displays are not in the HTML we can read. That is recorded as a platform irregularity, not worked around: no hidden API, proxy or identity rotation was used.

robots.txt

Read this session. It disallows /api/, /sports/, /events.php and the Python-urllib agent, and lists four sitemaps. This desk used only the sitemap and the public hubs, and did not touch a disallowed path.

Consequence for this release

Because the OLBG event list could not be read, the fixture slate comes from governing bodies instead. That is a stronger source for a kick-off time and a weaker source for “what OLBG is currently offering”. Both facts are stated plainly rather than blurred.
