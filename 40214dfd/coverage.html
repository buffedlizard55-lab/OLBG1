Why eleven sports have no rows

Eleven of the seventeen sports produced no publishable row because an official page did not yield a verifiable fixture list or a verifiable form input in this session:

  • Tennis — the ATP tour scores page returns live cards and completed results, not a future order of play, and the rankings table did not render.
  • Darts — the PDC tournaments page returned a consent wall and no fixture text.
  • Australian rules — the AFLW fixture and ladder widgets are JavaScript-only; the retrieved HTML contained no rows.
  • Rugby union — the United Rugby Championship fixtures URL returned a 404.
  • Cricket — the ICC matches URL returned a 404.
  • Rugby league, handball, volleyball, golf, motor racing, eSports, greyhounds — no official fixture page was read, so no row and no price is claimed.

Each of these is a coverage failure, not a finding about the sport. Filling them from memory or from an aggregator would break the verification rule this desk is built on.
