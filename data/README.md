# data/

- `matches.csv` / `matches.json` — 164 events, OLBG snapshot 2026-10-21.
  Generated by `scripts/build_data.py` (raw transcription + model formula in
  that file; do not edit outputs by hand).
- Columns: fixture/date/time as displayed by OLBG · leading market/selection ·
  tips for/total/share · experts · `winner_pick` + `pick_basis` ·
  `model_prob_pct` · `originated_fair_decimal` (+ opponent) · `confidence` ·
  `bookmaker_odds` (always blank — not visible on OLBG, see Flag F-03) ·
  `olbg_event_url` / `olbg_sport_url` (source per row) · `flags`.
- Method: `research/methodology.md`. Verification: `research/verification-log.md`.
