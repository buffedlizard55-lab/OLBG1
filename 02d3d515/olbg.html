Routes that work

Each sport is a numeric route. The hub lists one row per event with the most-tipped selection, a tip share and a start time. Ticking "Show Expired Events" reveals matches that have already started, which is why the hub cannot be treated as a list of upcoming fixtures.

The event page is where the markets are

Opening an event gives a full market ladder. For the ATP final the page exposed Win Match, Set Betting (four scorelines), 1st Set Winner, Games Won at ±4.50 and Total Games at 21.50. For baseball it exposes Money Line, Run Line and Game Totals; for ice hockey Money Line and Game Totals; for basketball Money Line and Pointspread. That ladder is what we used to decide which markets exist — not to set our prices.

Limits we hit

  • The hub shows "Today" times even after kick-off, so every listing has to be re-checked against the official schedule.
  • Start times are displayed in US Eastern for North American sports and UK time for European ones; both are converted to UTC here.
  • Tip counts are community opinion, not probability. We record them but never price from them.
  • Golf renders "No tips found." while the tournament is live.
  • Some sport hubs (Rugby League) have no open match market at all outside outrights.
