1. Defects found and fixed in this pass (15)

These are the defects this pass found on the published board. Each fix is in this commit; the two that cannot be fixed without moving every price or re-fetching a live source (F-26B-06 draw mass, F-26B-10 fetch limit) are disclosed instead.

ID Finding What was done Evidence
F-26B-01Pick cards linked to a Google search, not an official source
The 22 October board's ten high-confidence cards each ended in a google.com/search link. That is an aggregator, not a governing body, and it broke the rule that every row carries an official link.
Replaced with the fixture's own official source links, which were already recorded on the row.predictions.html · policy
F-26B-02US odds could print outside the −250 floor they claimed to respect
US odds were converted from the model probability instead of from the published decimal, so a 1.40 line printed as −251 — outside the window the page said it enforced. One high pick (aflw-r11-09) was affected.
US odds are now the exact conversion of the decimal shown beside them: 1.40 is −250, not −251. A gate now fails the build if any row disagrees.afl.com.au/aflw/ladder
F-26B-03Pricing assumptions were not published per row
Sigma, slope, home-field adjustment and the total baseline were applied from per-sport tables but stripped out of the published fixture export, so a reader could not reproduce a price from the site alone.
Every fixture now exports its assumptions, and the per-sport table is printed on the methodology page.methodology.html#assumptions
F-26B-04A prediction misdescribed its own handicap unit
The Samoa Women preview said the line sat at “a converted try and a half”. The selection is a 1.5-point handicap; a converted try is six points, so the sentence described a nine-point line that is not on the card.
Rewritten to “more than a point”, which matches the 1.5-point handicap actually priced.nrl.com women's Round 2
F-26B-05Two previews asserted facts that were not in the sourced input
“The deeper rotation” (Panathinaikos) and “superior goal difference” (Magdeburg) are not values the official standings captured for those rows, so they could not be verified and were removed.
Both previews now quote only the sourced record: win-loss, points and differential where it exists.EHF standings
F-26B-06Draw mass is omitted from every non-binomial sport
The normal model prices a two-way winner (p and 1−p) for all sports, including handball, Gaelic football, rugby union, rugby league and AFLW, where a draw is a real outcome. A favourite's win probability is therefore slightly overstated and a draw is never quoted.
Disclosed, not silently patched: changing the model mid-snapshot would move every price. Flagged for the next pricing pass, which should add a draw component for draw-capable sports.methodology.html#limits
F-26B-0728 rows carry a verification date they did not earn today
These rows were read from an official page on 21 October and not re-read for the 22 October snapshot. They keep their official link and are labelled carried, and the grading rules cap them at Medium.
Counted per sport on the verification page; each row shows its own status.verification.html · policy
F-26B-08Seven cards have no market at all
Four golf tournaments, Formula 1, League of Legends and the GBGB meetings are listed as event cards because no entry list or fixture was captured. Without a field there is no head-to-head and no honest price.
Published as event cards with the reason and the official link; no selection is invented.picks.html · policy
F-26B-0914 rows have no UTC start time
Some official sources publish a date without a clock, or a local clock without a timezone. Converting those would be a guess, so the UTC field is blank and the official local wording is kept.
Listed in full below with the wording each source used.verification.html · policy
F-26B-10This integration pass could not re-fetch any official page
The sandbox used for this pass can reach GitHub and the package registries only. No league, tour or governing-body host was reachable, so no row was re-certified here.
Every check this pass could make offline is listed on the verification page, and the limitation is printed there rather than hidden. The recorded verification dates are the ones the reading sessions stamped.verification.html#limits · policy
F-26B-11One volleyball source now redirects away from the men's competition
plusliga.pl serves the men's schedule but redirects the public page to the women's TAURON Liga site, so the men's fixture cannot be re-certified from that URL.
The row stays carried and capped at Low; the redirect is recorded on the sport page.plusliga.pl/games.html
F-26B-12The greyhound regulator returned HTTP 500
gbgb.org.uk failed at capture time, so no race card, trap draw or price could be read.
The meeting is listed as an event card with no selection.gbgb.org.uk
F-26B-13The official-host allowlist did not include two of the snapshot’s own sources
The tennis rows are read from the WTA draw PDF on wtafiles.wtatennis.com and the ATP order of play on www.protennislive.com. Both are the tours’ own file hosts, but neither was on the validator’s allowlist, so a strict run of the old gate would have rejected the snapshot’s best tennis sources.
Both hosts are now on the shared allowlist and every row is re-checked against it on each build.ATP order of play
F-26B-14A missing rating was filled with a league-average prior and then priced as if it were measured
39 of the 120 priced matches have at least one side with no captured official rating. The model substituted 58.0 and subtracted it from the rated side, so an unrated opponent created an edge nobody measured: Medvedev at 97.5 against an unrated player produced a 39.5-point gap and a 1.22 moneyline. The repository's own rule said one-sided ratings are refused, so the code and the documentation disagreed.
Fixed at the root: when either side is unrated no strength edge is applied at all, the price is the venue baseline, and the desk publishes no tip on that card. The match-winner call stays visible and is graded Low. 46 of 120 matches now carry no tip, 39 of them for this reason.ATP rankings
F-26B-15Cricket mixes three formats under one scoring baseline
The four cricket rows cover two T20 internationals, a first-class match and a one-day domestic match. The model applies one run baseline (170.5) and one spread (22) to all four, which fits a T20 innings and badly misfits a three-day game. The basketball table already separates the NBA from the EuroLeague; cricket does not yet separate its formats.
Disclosed on the sport page and in the methodology table rather than patched with invented per-format baselines. Flagged for the next pricing pass, which should carry a T20 / one-day / first-class baseline triple.NZC fixtures
