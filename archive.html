The 21 October root board

The root used to serve a 134-row board built from data/fixtures.json. It is preserved verbatim under archive/root-20261021/ so its pages, tables and verification ledger remain reviewable. Its dataset still ships in the repository and is still covered by scripts/validate.py; it is simply no longer the current snapshot.

Reports and data

  • reports/LIVE_VERIFICATION.md — the page-by-page verification ledger.
  • reports/FINAL_INTEGRATION_AUDIT.md — the row-by-row audit of the 21 October primary data.
  • reports/SESSION_* — each session’s own findings, unedited.
  • data/v3/ — the snapshot data behind this site; data/final/ — the joined bundle this site renders.
  • Analysis — market-level analysis on the snapshot.

One desk, one snapshot. Every row links to the official league, tour or governing-body page it was read from. Prices are the desk's own fair-price estimates, not quoted market odds. Nothing here is a tip-off service or a guarantee.
