What would close the gaps

  • Basketball (NBA). Three public endpoints returned HTTP 500 or an Akamai rejection. The untried routes are the static league schedule JSON and the per-team schedule pages.
  • Darts. pdc.tv serves a consent document in place of page content; the draw is likely reachable from a tournament sub-path that skips the consent template.
  • Rugby union. The United Rugby Championship fixtures path has moved; the competition's own navigation points at a different slug.
  • Handball. The French league renamed its competition to Daikin StarLigue, so the old calendar path is dead; the live path is the renamed one.
  • Golf. OLBG itself returned "No tips found." on every golf hub, so there was nothing to reverse-engineer, and the PGA Tour season index path 404s.
  • Greyhounds. The GBGB race-card path returns the organisation's 404 template; the racing section index is the working entry point.
