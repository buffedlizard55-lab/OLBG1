Known structural irregularities on OLBG itself

  • Each-way blank-percentage bug. The T20 Blast 2027 outright card (event 188350) renders its consensus column as 0/0 with an empty percentage while still showing tip counts. The same pattern appears on other ante-post each-way markets.
  • Silent empty hubs. The golf hub answers with "No tips found." rather than an error or an empty-state code, so an automated harvest that only checks HTTP status will record a successful read of an empty sport.
  • Outright-only sports. Rugby league published three ante-post outrights and no match cards at all, which is indistinguishable from a coverage failure unless the page body is parsed.
  • Viewer-zone clocks. Every clock is rendered in the reader's own timezone with no zone label anywhere in the markup, so a harvest without an independent cross-check will silently shift every start time.
  • Expired cards stay listed. Elapsed events remain on the hub marked "Expired", mixed in with live ones, which is how several of this morning's tennis and snooker cards were still present at harvest time.
