How OLBG is put together

The route pattern, what the hub pages actually contain, and where the traps are.

Routes

Every sport hub follows /betting-tips/<Sport_Name>/<sport_id> and every event follows /betting-tips/<Sport>/<Group>/<Competition>/<Home>_vs_<Away>/<sport_id>?event_id=<id>. American sports use an @ instead of _vs_. The sport id is stable across both route shapes.

What a hub row contains

  • The most-tipped selection for the event, not every selection.
  • The market name: Money Line, Pointspread, Handicap, Win Match, Win Match 2-way, Set Score, Draw No Bet, Top Team1 Batsman, Daily Races, Win Race, Win Tournament.
  • A tip count and a share, for example "13/19 Win Tips 68%". That is a vote share.
  • A rendered start time that matches US Eastern on every row we could cross-check.
  • No odds. The price column is loaded client-side and does not appear in the served page.

Traps we hit

  • Golf renders "No tips found." with no explanation.
  • Rugby League renders outrights for 2027 only.
  • Greyhound rows print the UK race clock in the event name and an ET clock in the time column, five hours apart.
  • Tennis rows carry no tournament tag at all.
  • Expired events are still in the DOM; one greyhound row was marked expired while still rendered.
