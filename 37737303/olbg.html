What the hubs hide

  • Zero-tip events vanish. A fixture with no community tip is not rendered, which is why golf, snooker and motor racing read as empty even though their seasons are running.
  • Twenty-row cap. The default table stops after roughly twenty upcoming events and needs a "Load more tips" click, so a hub read can miss fixtures that a competition sub-route shows.
  • Unlabelled clocks. Times are edge-local with no zone suffix. The same match can read "Today 19:07" on one route and a different hour on a cached sub-route.
  • Wrong label on the sports menu. The golf and motor racing hubs rendered "All Sports" in the menu where the sport name belongs, which is a rendering fault rather than a data one.
  • Event links carry the id twice — once as a path segment and once as an event_id query parameter; both are needed to reopen the exact market.

The three sports with no market

Golf — The golf hub returned 'No tips found' at 22:40Z: no tournament carried an open tip. A search of the page's own sports menu also fell back to 'All Sports', which is the same hub-rendering fault recorded in earlier sessions.

Snooker — The snooker hub returned 'No tips found'. The World Snooker Tour page for the Northern Ireland Open showed round-one results from 18-19 October but did not return the current session, so no upcoming match could be paired with a market.

Motor Racing — The motor racing hub returned 'No tips found'; the page's own 2026 calendar table ends before a round that falls inside this desk's window, so there was no race to price.
