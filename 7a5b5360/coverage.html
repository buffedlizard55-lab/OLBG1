What "state" means

  • verified — fixture facts read on an official page, both sides have a sourced input.
  • verified fixture only — the fixture is confirmed but no strength input was readable, so the price is neutral and the tier is capped.
  • no fixture in window — the official board was read and publishes no in-scope match for 22–26 October.
  • blocked / client rendered — the official page was reached but served no fixture data to this client.
  • not attempted — the sport has no static official board this session; named so the gap is explicit.
