Methodology

Tier rules (this desk)

HIGH: future at cutoff + priced + strict window + both sides officially rated and measured + ledger-fresh (confirmed/corrected) + hand-authored >=30-word prediction. MEDIUM: future + priced + window + both rated, missing another High gate. LOW: all other future priced rows. Expired/undated/unpriced rows publish with a null tier.

Pricing

Fair (0% overround) headline odds with the 5%-vig book price alongside, per the repo's published model conventions (scripts/model.py). The High window is judged on the book price, strictly inside -250..+10000.

Ratings and probabilities come from the repo's published model conventions (scripts/model.py) applied to official governing-body inputs stored per row in data/fixtures.json — points percentages, ladder positions, IRL/ICC rankings, EHF group tables and measured splits. The desk does not originate new numeric ratings; it originates the tier gates, the harvest evidence layer and the predictions.

Harvest method

Each of the 17 in-scope OLBG sport hubs was fetched live this session via the canonical hub URL pattern https://www.olbg.com/betting-tips/{slug}/{id} (chunk 0 of each hub's paginated text layer). Every recorded card carries the rendered event_id, matchup, unlabelled time string, most-tipped selection, market label where rendered, and tip counts exactly as displayed. Deeper pagination chunks were not re-read; per-hub chunk coverage is recorded in each file. No value is inferred: blank fields stay null.

Excluded hubs (never fetched): Football/1, Horse Racing/2, American Football/11, Boxing/16, Cycling/17, Specials/18, Hurling/26 - excluded by the client brief; not fetched this session.

Verification policy

Every row links the official source(s) it was built from; the live verification ledger ({'rows': 134, 'confirmed': 44, 'corrected': 32, 'flagged': 2, 'not_rechecked': 56} rows) records per-row re-checks. Where a value cannot be confirmed officially it is left blank and flagged — never inferred.
