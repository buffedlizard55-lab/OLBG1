Fresh factual review

This release transcribes 97 fixture/event observations from identified official sources, with field-level references and explicit read scope. All 17 OLBG hubs were read at their first chunk. The review ledger records missing times, absent inputs, orientation corrections, conflicting records and excluded inherited prices. This is not a manual factual review of every line in every historical desk.

Whole-repository line inventory

The inventory tool enumerates tracked and newly authored files, counts UTF-8 lines, fingerprints every file and records line numbers for source URLs and risk terms. It supplies exact GitHub manual-review links and distinguishes generated, canonical and historical files. It is an automated inspection aid, not proof that every historical sentence is true.

Executable gates

The current validator checks eligible categories, source roles, paired inputs, probability complements, fair-odds arithmetic, past-start handling, freshness, no neutral missing-data prices, absent approved bets, unique commentary and local links including fragments. Unit tests exercise malformed data, timezone ambiguity, draw handling, score-grid mass, boundary odds and failed refreshes. Live external URLs are not certified merely by structural tests.

Preservation

Prior root HTML is archived; every namespaced desk and dataset is retained unchanged. The independent T56/T57 audit scripts and reports are not overwritten. The old generators remain historical and are no longer the canonical publishing command.

Unresolved user goals

Exhaustive all-market, all-match coverage and empirically supported new High selections are not completed. Rather than disguise those gaps with verification labels, the release exposes them and approves zero bets.
